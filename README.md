DJAssist Grabber

Plugin de Nicotine+ con una interfaz web para buscar y descargar los tracks de una playlist desde Soulseek. Vos elegís qué bajar de cada track — nada se descarga solo.

    ¿No sos técnico? Abrí LEEME.txt: guía completa, paso a paso, de instalación y uso (también queda una copia en Música/DJAssist Grabber/ después de instalar).

Instalación

No hace falta usar la Terminal.

    Descargá este proyecto (botón verde "Code" → "Download ZIP" en GitHub) y descomprimilo
    Hacé doble click en:
        Mac: Instalar.command
        Windows: Instalar.bat
    Seguí las instrucciones en pantalla (si no tenés Python o Nicotine+ instalados, el instalador te lleva a la página oficial para bajarlos)
    Abrí Nicotine+ → Preferencias → Plugins → activá DJAssist Grabber
    Abrí http://127.0.0.1:8765 en el navegador

Requiere Python 3 instalado en tu compu (el instalador te avisa y te manda a bajarlo si no lo tenés).
Qué hace

    Importa playlists en .txt, .csv, .m3u, XML de Rekordbox, o directo desde una captura de pantalla (OCR, instalable desde la propia web la primera vez que subís una imagen)
    Busca en Soulseek con hasta 4 búsquedas en simultáneo (ajustable)
    Te muestra los candidatos encontrados — vos elegís cuál bajar
    Si no aparece nada en Soulseek, te arma la búsqueda en Bandcamp y SoundCloud
